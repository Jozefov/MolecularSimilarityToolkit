# Private release review

This repository starts private. Public visibility, hosted documentation and
PyPI publication are separate owner-approved release steps.

The release review checks correctness, interruption recovery, clean installation,
platform CI, document build, editable artwork and measured scale behavior.
Large molecule collections and private benchmark inputs stay out of Git.

Measured evidence is added here after verification completes. The package
must not claim whole-PubChem performance based on a subset or synthetic test.
